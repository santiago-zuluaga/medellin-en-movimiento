# Estructura del informe final

1. Basic Info
   - título, equipo, curso, demo.
2. Overview
   - problema, motivación, público, resumen y teaser.
3. Data
   - ficha por dataset: descripción, URL, licencia, tipo, cardinalidad, atributos, rango, limpieza, limitaciones.
4. Tasks
   - tareas en lenguaje de dominio y abstracciones analíticas.
5. Visualizations
   - overview, cada vista, marks and channels, escalas, Gestalt, interacciones, complejidad y accesibilidad.
6. Usage Scenario
   - escenario narrativo paso a paso con filtros y vistas coordinadas.
7. Reflections
   - cambios, límites, decisiones descartadas, trabajo futuro.
8. Work Breakdown & Schedule
   - responsables, estimaciones y horas reales.
9. Credits
   - fuentes, bibliografía y librerías.

Para cada figura: número, título, descripción y referencia cruzada en el texto. Las afirmaciones cuantitativas deben indicar periodo, filtro, unidad y fuente.
