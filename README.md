# Medellín en movimiento — Codex Starter Kit

Este paquete contiene instrucciones de proyecto, propuesta, plan de validación, diseño preliminar y ocho skills para Codex.

## Cómo instalar
1. Descomprime el paquete en la raíz del repositorio.
2. Conserva `AGENTS.md` en la raíz.
3. Conserva `.agents/skills/` con sus ocho carpetas.
4. Abre el repositorio en Codex.
5. Pide a Codex que lea `AGENTS.md` y las skills relevantes.
6. Empieza por la Fase 1. No le pidas implementar el dashboard antes de validar los datos.

## Estructura
- `AGENTS.md`: reglas permanentes del proyecto.
- `.agents/skills/*/SKILL.md`: instrucciones especializadas.
- `docs/`: documentos de investigación y diseño.
- `scripts/profile_local_data.py`: perfilado básico de CSV/Parquet/GeoJSON locales.

## Importante
El inventario de fuentes es preliminar. La existencia de metadatos oficiales no equivale a haber descargado y auditado los ficheros completos. Actualiza `DATA_VALIDATION_PLAN.md` con los resultados reales del perfilado.
