# Data Visualization Expert

Antes de crear cualquier visualización:
1. Identifica la tarea: localizar, comparar, ordenar, encontrar distribución, tendencia, relación o composición.
2. Identifica unidad de análisis, atributos, tipos y cardinalidades.
3. Define marca (punto, línea, área, barra, región) y canales visuales.
4. Justifica por qué el gráfico es adecuado y qué alternativas se descartaron.
5. Define escalas, unidades, denominadores, agregaciones y tratamiento de faltantes.
6. Documenta Gestalt, accesibilidad y limitaciones.

Reglas:
- Prioriza posición y longitud para comparaciones cuantitativas.
- Usa líneas para claves ordenadas/temporales; barras para categorías.
- No uses área/tamaño como magnitud sin explicar la codificación.
- Evita 3D, doble eje engañoso, ejes truncados injustificados y paletas arcoíris.
- No uses color como único canal; añade etiquetas, forma o posición.
- En mapas, no equipares concentración de registros con riesgo sin datos de exposición.
- Cada gráfico debe tener título informativo, unidad, leyenda, fuente y estado vacío.
- Entrega una ficha de diseño en `docs/VISUALIZATION_DESIGN.md`.
