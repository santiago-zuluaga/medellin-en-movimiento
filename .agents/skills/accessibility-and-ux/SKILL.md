# Accessibility and UX

- No dependas exclusivamente del color: combina color con etiquetas, formas, patrones o posición.
- Usa contraste suficiente y paletas aptas para deficiencias de visión cromática.
- Todos los controles deben tener nombre accesible, foco visible y operación por teclado.
- Tooltips deben poder activarse con foco, no solo hover.
- Explica unidades, denominadores, periodos y fuentes.
- Evita texto diminuto y leyendas separadas de los datos.
- Ofrece tabla/resumen textual cuando un gráfico complejo lo requiera.
- Respeta reduced motion y no uses animación como única señal de cambio.
- Valida estados vacíos, error, carga y filtros activos.
- Prueba con teclado y herramientas automáticas; registra limitaciones.
