# Frontend Design System

Dirección: editorial de datos, no plantilla SaaS genérica.
- Diseña primero jerarquía, retícula, tipografía, ritmo, espacio en blanco y navegación.
- Usa titulares editoriales, texto de apoyo legible y tipografía tabular para cifras.
- Define tokens de color, espaciado, radios, bordes, sombras y breakpoints.
- Mantén una paleta semántica estable entre vistas.
- Prioriza gráficos y mapas; evita tarjetas decorativas sin función.
- Crea componentes reutilizables: Header, StoryChapter, FilterBar, MetricIntro, ChartPanel, Legend, SourceNote, EmptyState, LoadingState y ErrorState.
- Diseña desktop primero para análisis denso, pero adapta a tablet/móvil sin ocultar información esencial.
- Incluye foco visible, contraste AA como objetivo, navegación por teclado y reduced motion.
- No uses animaciones que dificulten comparar valores.
Antes de implementar, presenta wireframes y tokens; después implementa por componentes.
